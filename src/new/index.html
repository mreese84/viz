Add a poster

Turn a set of Strava rides into a poster for the gallery. For the site owner: it needs your Strava login and a GitHub token.

Setup needed

This page needs the Strava login Worker. Deploy it (see workers/strava-auth/README.md in the repo), put its address in src/site.json as "stravaWorker", and push.

1Rides

Activity numbers on their own work too. Rides are put in date order.

2Your rides

    DateRideDistanceClimbing

    3Poster text

    A long title wraps onto two lines to fit the disc.

    {rides} and {regions} become counts.

    4Regions and towns

    Every ride needs a region; rides in a row with the same region share one coloured band. The town shows when you hover over a ride.

    RideRegionTown (optional)

    5Climb labels

    Suggested from each ride's Strava segments, biggest climbs first. Tick the ones to label and edit the names. Labels sit at each climb's highest point.

    7Publish

    Publishing commits the poster's files to and the site rebuilds itself, usually within a minute or two.
